Generated with the built-in image_gen tool. These are the current continue-learning backgrounds. Course cards retain their original minimal SVG artwork. Original PNGs: `*-v2.png` in this folder. App assets: `public/artwork/biomes/*-v2.webp`.

The user's attached screenshot was the style reference for each image. The revisions simplify pixel clusters and integrate course-specific code into the scenery.

## Shared prompt

Use case: stylized-concept. Create ONE 3:1 wide landscape pixel-art background for a course continue banner. Use attached image ONLY as art direction, NOT as a UI to reproduce. Landscape only, no interface, buttons, border or title overlay. Aim for authentic hand-placed pixel-art game scenery: deliberately low-resolution chunky square pixel clusters like an approximately 512x176 game background enlarged cleanly; limited muted palette, 3-4 tones per material, readable simple silhouettes, irregular organic shapes, restrained detail, sparse grass tufts, flat stepped shadows, subtle distance haze. No painterly brush strokes, no glossy bloom, no high-frequency confetti texture, no tiny pseudo-detail, no smooth digital-painting gradients, no ornate fantasy filigree. Peaceful, natural, soft pastel mood. Preserve open quiet left 40% for later UI overlay; important scenery and the requested code inscriptions on the right half. Code is physically engraved or painted on scene objects in simple readable pixel lettering, never floating UI. Code should be limited to the few short requested inscriptions, accurate characters and punctuation. Same gently elevated landscape perspective as reference. Edge-to-edge finished landscape.
