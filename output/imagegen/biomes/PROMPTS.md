Generated with the built-in image_gen tool from the user's soft pixel-art reference. Original PNGs are preserved here; optimized WebP copies are in `public/artwork/biomes/` for the app. Each image is 2048 × 683.

Reference roles: the attached UI image supplied the style and composition. CSS, JavaScript, TypeScript, and Next.js also used the generated HTML scene as a visual consistency reference.

## Shared prompt

Use case: stylized-concept. Generate one standalone landscape background illustration for a coding course banner, wide 3:1 composition. Input image is ONLY a style and landscape reference: match its soft pastel pixel art, deliberate visible square pixels, chunky low-resolution shapes, gentle atmospheric depth, cozy adventure-game environment, muted lavender shadows and warm light. Produce the landscape ONLY, edge-to-edge. No UI, no text, no letters, no logos, no buttons, no progress bar, no border, no black margins. Keep left 40% visually quiet with low-detail ground/water and distant scenery for later HTML text overlay; put the beautiful focal architecture in right half. Not isometric, use the same gently elevated landscape perspective as reference. Avoid photorealism, smooth vector edges, microdetail and harsh outlines.
